# Project: Multi-Agent Travel Planner
- **Frontend:** React (Vite), TypeScript, Tailwind CSS, Lucide React (icons).
- **Backend:** Python, FastAPI, LangGraph, Google GenAI SDK (Gemini API).
- **UI Style:** Glassmorphism (`backdrop-blur-lg`, `bg-white/20`, `border-white/30`). Backgrounds must be soft, flowing pastel gradients. No harsh borders. 
- **Architecture:** The backend must implement a parallel multi-agent graph where an Attractions Agent and a Culinary Agent run simultaneously before passing data to a Synthesizer Agent.
- **APIs:** Strictly use Gemini (Free), OpenStreetMap, and Overpass API. Do not use paid APIs like Google Maps.
